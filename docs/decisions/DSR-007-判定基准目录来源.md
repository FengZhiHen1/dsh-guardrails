# DSR-007：判定基准目录来源——对齐 `sandboxPolicy.resolve()` 会话身份

> 状态：**已决议（2026-09，随 v1.4.0 重构落地）**。本文记录 pwsh/相对路径判定的
> 基准目录（base）来源从 `session.meta.cwd` 改为 `sandboxPolicy.resolve({ session }).workspaceRoot`
> 的实证过程与决策。这是行为修正（bug fix）：旧读取链在 0.1.2-rc.1 上恒失效。

## 上下文

守卫对相对路径目标（`Remove-Item .`、`cd sub; Set-Content x y`、省略 `workdir`
的 pwsh 命令）的判定依赖一个基准目录（base）：`resolvePath(base, target)` 之后
才谈得上"是否命中敏感目标"。v1.0–v1.3 的实现是：

```js
const cwd = agent?.session?.meta ? agent.session.meta.cwd : undefined
const base = typeof cwd === 'string' && cwd ? cwd : sandboxPolicy?.workspaceRoot ?? ''
```

2026-09 对照 0.1.2-rc.1 源码实证（`packages/core/session/src/index.ts`、
`packages/sandbox/sandbox-policy/src/index.ts`）发现两个问题：

1. **`Session` 公开面无 `.meta`**。`meta` 只是 `sessions.create()` 的输入选项，
   经校验后映射进不可变的 `SessionHeader.cwd`（`session.header.cwd`）；`Session`
   实例只有 `header` getter。旧读取链 `session.meta.cwd` 恒为 `undefined`，
   防御链静默落到 fallback——base 实际是 **`sandboxPolicy.workspaceRoot`
   （部署 fallback 根，默认 DSH 进程启动目录）**，不是会话工作区。
2. **官方工具链的身份来源**是 `sandboxPolicy.resolve({ session }).workspaceRoot`
   = `resolveWorkspaceRoot(session.header.cwd ?? fallbackRoot)`（`canonicalPath`
   解 symlink + `node:path.resolve` 绝对化）——"约束与启动使用同一身份"
   （tool-pwsh/tool-bash 均如此解析 workdir）。

后果：base 指向 DSH 启动目录时，相对路径的删除/写入判定坐标系错误——既可能
漏拦（真实目标是工作区根，解析后不等于 base），也可能误伤。mock 测试因迎合
旧形状（`session: { meta: { cwd } }`）从未暴露此问题。

## 决策

base 来源改为：

```js
const session = execution.agent?.session
const base = sandboxPolicy?.resolve(session ? { session } : {}).workspaceRoot ?? ''
```

- `sandboxPolicy` 挂载时：base = 规范化的 `session.header.cwd`（无会话/无 cwd
  时回落部署 fallback 根），与官方工具链同一身份；
- `sandboxPolicy` 未挂载时：base = `''`（现状行为保留：相对路径按段解析，
  绝对前缀规则不命中——官方 base bundle 必挂 sandbox-policy，此分支仅为
  防御性降级）；
- pwsh 显式 `workdir` 仍相对 base 解析（与 tool-bash "workdir 相对会话 cwd"
  语义一致）。

## 代价与边界（显式记录）

- `resolve()` 每次工具调用执行一次 `realpathSync.native(cwd)`：cwd 必存在
  （会话工作区），不触发 catch 回落分支；同步热路径开销为微秒级，可接受。
  不引入缓存（缓存即状态，状态即失效问题）。
- README"纯静态分析不碰 fs"的措辞精确化：**目标路径**不做任何 fs 探测
  （symlink 逃逸不可探测的边界不变）；**基准目录**做身份解析（realpath），
  性质是定位判定坐标系，不是探测目标。
- mock 测试的 session 形状同步修正为 `{ header: { cwd } }`（真实形状），
  并补 sandboxPolicy 缺席/会话缺席两条回落测试。
