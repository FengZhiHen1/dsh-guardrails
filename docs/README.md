# dsh-guardrails 文档入口

## 当前状态与阅读顺序

本插件只防**灾难性删除**，采用 **L1/L2/L3 三级标准**：**L1 灾难性删除直接拒绝**（物理设备、宿主系统整树、`.git` 元数据、销毁 git 历史的子命令）；**L2 可识别命令行删除计数**（≤20 放行、>20 拒绝）；**L3 其余一律放行**。执行通道（目的是执行任意命令文本的通道）在无法分析时拒绝；插件**不声称覆盖所有删除**。源码与隔离 Runtime 验证通过，详见[验证记录](verification/2026-11-14-delete-gate.md)。live 激活已在验收环境复验；**UI 显示、稳定环境部署与 Linux/跨平台实跑尚未完成**，以验证记录为准。

先读需求确认产品范围，再读技术入口了解机制；灾难性删除标准见 DSR-020，删除计数与不确定执行拒绝的取舍见 DSR-019（覆盖 DSR-017 中与之冲突的条款，历史 DSR 原文不改）。**v6 的触发收敛（非删除语义 unknown 不再拒绝）与定向提示**见 DSR-021。早期 ask-only 架构由 DSR-017 演进；DSR-001…016 保持历史记录，不作为当前默认规则清单。
