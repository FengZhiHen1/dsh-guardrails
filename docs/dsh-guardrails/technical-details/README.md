# dsh-guardrails 技术细节

## 权威范围

本文是 `dsh-guardrails` 技术细节目录的入口，唯一拥有本目录的阅读顺序与文档地图。机制事实归各机制文档；本文不重复定义机制。

## 阅读顺序

1. `rule-model.md`：先读拦截模型——敏感类别 × 操作类型矩阵、路径级与命令文本级检查、名单结构与 fail 语义。
2. `command-analysis.md`：再读命令文本分析——词法、动词分类、列举模式判定、破坏性分析与固有限制。
3. `engineering.md`：读源码结构与测试体系——lib/ 模块边界、四层测试、覆盖率门禁与验证流程。
4. `deployment.md`：最后读包形态、部署红线、生效流程、测试与发布路径。
