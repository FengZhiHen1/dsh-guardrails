# dsh-guardrails 批量删除白名单

本文定义「可丢弃构建产物与缓存」的内置识别范围。它是删除数量门禁的**计数证据**：命中的**常规文件**在**通过证据校验**后不计入 20 文件上限。命中不是删除许可——受保护文件、绝对 Deny、链接/挂载边界、项目边界与证据规则仍然生效；未通过证据或未识别条目一律照常计数。

实现见 `src/core/disposable.js`（纯同步文件形态匹配）与 `src/adapter/disposable-evidence.js`（异步归属/再生证据）。核心匹配器只按「项目 marker + 约定产物位置 + 文件形态」判定，无文件系统 IO；证据适配器再证明该形似产物确实可丢弃，任何无法证明的情况都照常计数。

## 命中语义（计数-only，文件级，需证据）

- `classifyDisposable({ relativePath, projectMarkers, isDirectory })` 返回 `{ disposable: true, ruleId }` 或 `{ disposable: false }`。**返回 `disposable:true` 只是候选**，不自动减计数。
- 真正减计数需**同时**满足：核心匹配器 `disposable:true` **且** 证据适配器 `createDisposableEvidence(...).verify({...})` 返回 `eligible:true`。任一不满足即照常计数（保守方向）。
- **只识别常规文件。** `isDirectory:true` 一律返回 `disposable:false`，不提供「整目录豁免」。
- `relativePath` 用 `/` 分隔，相对已确证的项目根；出现绝对路径、盘符、UNC 根或 `..` 段一律 `disposable:false`。
- `projectMarkers` 是调用方在项目根确证存在的**精确 marker 文件名**（basename），例如 `pyproject.toml`、`Cargo.toml`。marker 名区分大小写；路径式或未知 marker 被忽略。marker 只用于**定位项目根（边界发现）**，其存在本身从不授予豁免。
- 白名单对符号链接/链接条目 `false`：链接不被跟随、不被豁免，作为删除条目计数。

## 证据规则（真正决定能否减计数）

证据适配器在核心形态命中后进一步要求（全部满足才 `eligible:true`）：

1. **项目边界包含**：产物位于「可信 `projectBoundary`（沙箱工作区，独立于执行 cwd）→ 项目根 → 产物」之间，按**规范分隔后的精确段前缀、区分大小写**比较。仅大小写别名不算包含（NTFS 可有大小写敏感目录，`C:\repo` 与 `C:\REPO` 可不同实体；无法证实即照常计数）。
2. **非归档/依赖域**：从 boundary 到项目根、以及项目根到产物的相对段中，任一命中 `backup/backups/archive/archives/snapshot/snapshots/node_modules/vendor/third_party/.git`（不分大小写）的段即拒绝（照常计数）。
3. **非链接逃逸、常规文件**：产物解析真实路径后仍位于项目内，且是常规文件。
4. **Git 归属**：产物不得是 Git 已跟踪索引条目；Git 状态必须可证（在产物所在仓库上做一次性缓存查询）。已跟踪或 Git 状态未知（不可用时）→ 照常计数。Git 比较允许大小写折叠——因为折叠只会**撤销**豁免，方向安全。
5. **再生源配对**：
   - Python `py-pyc-file`：需同目录 `__pycache__` 的父目录存在配对的 `<stem>.py`。
   - Maven `maven-class-file`：`target/classes/**` 需对应的标准 `src/main/java` 下同名 `.java`；`target/test-classes/**` 需 `src/test/java`；嵌套 `$` 内部类映射到外层 `.java`；支持默认包。不支持的源码布局/语言 → 照常计数。
   - TS `ts-buildinfo-file`：仅支持**有限子集**——见下。

## 有效文件规则（核心形态；仍需证据）

| ruleId | 文件形态（项目根相对） | 证据要点 |
|---|---|---|
| `py-pyc-file` | `__pycache__/<stem>.cpython-<ver>.pyc`（可带 PEP 488 `.opt-N`）；stem 须为严格 Python 标识符 | 配对 `<stem>.py` 源存在 |
| `pytest-cache-file` | `.pytest_cache/v/cache/{nodeids,lastfailed,stepwise}` | pytest 配置 marker + 项目/VCS 域 |
| `mypy-cache-file` | `.mypy_cache/<major>.<minor>/…/<module>.{data,meta}.json` | mypy 配置 marker + 项目/VCS 域 |
| `maven-class-file` | `target/classes/**/<Name>.class`、`target/test-classes/**/<Name>.class` | 对应 `src/main/java` / `src/test/java` `.java` 源 |
| `ts-buildinfo-file` | `<name>.tsbuildinfo` | 有界严格本地 `tsconfig.json` 且能按官方公式推出该路径 |

## TypeScript 有限子集（不追求全配置支持）

- 支持：显式 `tsBuildInfoFile` 覆盖；以及已确认的官方公式 `rootDir + outDir`（buildinfo 位于 `<outDir>/<config 相对 rootDir 的路径>/<config 名>.tsbuildinfo`）。
- **不自动豁免**：配置仅含 `outFile` 且无显式 `tsBuildInfoFile` 时，因官方文档对命名有歧义，两种猜测名都**照常计数**，不做猜测豁免。
- 拒绝（照常计数）：`extends`/`references`/子串命中的 `substring` 选项类型、无法有界解析的 tsconfig。本插件**不运行 `tsc`、不加载 TS SDK、不引入依赖**来推断；未知一律计数。

## 已移除 / 排除范围（明示不豁免，照常计数）

- **Cargo**：本轮**取消**依赖产物自动豁免（无法在不执行工具链的情况下证明其依赖来源）；`target/<profile>/deps/*.{rlib,rmeta,d}` 等一律照常计数。`Cargo.toml` 仅保留为**项目边界 marker**（用于定位项目根，嵌套 Rust 项目不继承外层 marker），其存在**不授予任何豁免**。
- **任意 `dist`/`build`/`out`/`bin`/`obj`/`tmp`/`temp`/`logs`/`backup`/`vendor`/`node_modules`/`coverage`/`.git` 等宽泛目录**：不做整树豁免。
- **`node_modules/` 整树**：依赖目录可能含用户补丁与凭据，无稳定证据，不纳入。
- **pytest/mypy 缓存目录内的其它文件**（`CACHEDIR.TAG`、非版本目录、非 `.json` 等）：不豁免。
- **Maven 其它产物**（`maven-status/`、`surefire-reports/`、`site/`、`*.jar` 等）：不豁免。
- **Gradle `build/`、Go 构建缓存/输出、PHP `vendor/`**：输出位置不稳定，不纳入。
- **任意 `.env`、凭据、私钥、锁文件、配置、源码文件**：即使伪装也不豁免。
- **用户自加白名单**：本模块不接受外部配置注入白名单；识别集合内置固定。

## 与数量门禁的关系

命中白名单且**通过证据**才减少计数，不是删除授权。删除计划适配器仍需：枚举非白名单常规文件、把链接条目作为删除条目计数、去重目录条目并单独报告目录数、对受保护文件与绝对 Deny 保持生效、无法确证语义时拒绝、对 Linux 挂载边界用 `/proc/self/mountinfo`（含同设备 bind 挂载）拒绝跨越、对无法表示的非法文件名字节拒绝。上限为 20；超过 20 可在「至少 21」处早停，但绝不能声称精确总数。整体清单/证据预算耗尽为拒绝（DEL-07），不作为放行。
