# dsh-guardrails 工程结构与测试体系

本文只声明验证分层边界与测试方法。模块边界、目录组织与依赖方向的结构权威在[架构重构设计](架构重构设计.md)「总体架构」节；本文不复述结构，只声明各层在验证中的边界与不变量。

## 分层边界声明

| 层 | 验证边界与不变量 |
|---|---|
| 包根入口 | 只验薄转发与 bundle 解析，不在本层验证策略 |
| `src/core/` | 裸 Node 可测：精确规则数据、路径与风险事实、判定映射、高置信打码；不得 import `@deepseek-ai/*`，不得反向依赖 adapter |
| `src/adapter/` | DSH 钩子、确认、执行关联、Provider IPC、目标身份探测、结果出口；依赖单向 adapter → core，不自造 Shell tokenizer |
| Parser helper / vendor | 官方 PowerShell 语法事实、固定 shfmt 二进制与校验元数据；不执行待审文本；平台包是否完整须另验 |
| `test/` | 稳定表驱动正反行为、Provider 与生命周期测试；合成凭据与隔离目标，不使用真实生产密钥 |
| `verify/` | 源码验证入口；只做语法与测试，不启动实例、不修改部署 HOME |

包与实例的交付条件归[部署](部署.md)「发布前置验证门禁」节；本文不重复其验收条件。

## 测试层与证据

| 层 | 应证明的行为 |
|---|---|
| 领域单元 | 精确目标、动作矩阵、优先级、Unknown 与故障区分、打码正反例和格式保真 |
| Parser 合同 | 官方 AST 有效/无效语法、引用文本/未调用函数不误判、插值/替换潜在执行、超时/崩溃/非法回包 |
| DSH 集成 | 同一 execution 对象关联、pre-execute 提前短路后最终 guard 仍拒绝、批准一次不可复用、never/迟到/取消 |
| 生命周期与资源 | helper 惰性启动/恢复/卸载，并发请求不串线；输入/输出/深度/并发有界；无遗留 timer/listener/进程 |
| 平台与目标 | Windows/Linux 分别实跑，cwd、大小写、symlink/Junction、Git common-dir/Worktree、镜像与真实设备身份 |
| 出口与持久化 | Native/PTC 的模型可见结果、SDK value、错误/meta/上下文、子调用日志、顶层结果、会话持久化逐一核验 |
| 包与实例 | 干净包安装/导入、二进制清单/哈希、peer、唯一激活行、自动设置页保存与功能 |

用 Node 内置 `node:test`。规则变化用稳定成对回归验证，不以重复实现算法的测试替代行为。行覆盖目标沿用 ≥80%，新覆盖率须真实采集，不继承历史数值。仓库分层检查运行 `node tools/plugin-layering-check.mjs plugins/dsh-guardrails`。

## 执行验证

按包实际脚本运行测试；必要时直接 `node --test test/*.test.mjs`，以区分测试失败与包管理器自动安装失败。

记录命令、平台、退出码、测试数量、耗时、skip 与证据范围。若失败源自 EPERM，不把它写成通过，也不把直接 Node 通过扩张为 `pnpm test` 成功。

`verify/` 只做源码语法与测试，默认不启动实例、不修改部署 HOME。实例启停另走官方启动器，且须已有授权。组合验证使用现场查询所得的目标实例版本 bin 与独立 HOME，不默认历史路径。

## 性能与回放

性能分别测 helper 冷/热启动、shfmt 每次启动的 p50/p95/p99、输入与 AST 大小、并发与恢复。测试套件总耗时不代表单调用生产延迟。

历史 97,050 条命令仅是资料规模，标注回放尚未完成；不得据此前的统计宣称新规则的误伤率或漏拦率。误伤与漏拦的评估以人工标注语料回放为准。
