# dsh-guardrails 技术细节

本目录承载插件机制文档。文档分两类，读之前先确认它属于哪一类：

- **目标契约（未编码）**：已确认、尚未按目标实现的机制设计。
- **当前实现**：代码当前展现的行为与交付事实。

## 阅读顺序

1. [规则模型](规则模型.md)：规则 schema、规则目录、判定顺序、删除分档细节、配置 A、确认、打码与失败分类。
2. [架构重构设计](架构重构设计.md)：**结构权威**。前门、类型化命令 IR、删除 sink、单一策略决策点、证据适配器、失败语义与旧→新映射。
3. [跨语言删除分析](跨语言删除分析.md)：Python/Node 入口识别、删除 sink、有界求值、动态目标转确认。
4. [命令文本分析](命令文本分析.md)：Shell 解析与包装解包。
5. [批量删除白名单](批量删除白名单.md)：可重建豁免的证据判据。
6. [工程结构与测试体系](工程结构与测试体系.md)：验证分层边界、测试层与证据、执行验证、性能与回放。
7. [部署](部署.md)：交付形态、平台要求、安装、配置键与发布门禁。

前五篇是目标契约，按上列顺序从判定模型读到机制细节。第 6 篇承载当前测试事实，第 7 篇承载交付事实；两篇可独立阅读。
