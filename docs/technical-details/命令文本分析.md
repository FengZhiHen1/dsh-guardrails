# dsh-guardrails 命令文本分析

## 官方 AST 与有限语义

本文拥有本轮 Shell 分析与最终门禁的实现契约；源码已实现并经过 Windows 测试，不表示已完成 Linux 运行验收。语法权威只有微软 PowerShell Parser 和官方 `mvdan/sh` AST。不得保留旧 `tokenizePwsh`、`splitFragments`、`maskTextSpans` 或新写 Bash lexer 作为第二权威、并集检测或故障回退。

| Provider | 固定接入 | 返回事实 |
|---|---|---|
| PowerShell | 惰性启动的持久受信 `pwsh` helper，调用 `System.Management.Automation.Language.Parser.ParseInput` | 有界结构化命令、参数、重定向、执行上下文、ParseErrors 与 Unknown |
| Bash | 本地官方 `shfmt v3.12.0 --language-dialect=bash --to-json`，`shell:false`、stdin 输入 | 官方 typed JSON AST，经验证后提取精简事实 |

shfmt 首版交付目标为 Windows x64、Linux x64/arm64，锁定版本、来源与校验和；不在工具调用时下载。旧研究中的 v3.14.1 是当时选型参考，不是本轮固定版本。不得要求运行机额外安装 Go 或 Bash 来完成文本解析。PowerShell 解析仍要求可信 `pwsh`，Linux 仅在确实提供 PowerShell 工具时加载其 helper。

待审文本是协议数据，不能 `eval`、`Invoke-Expression` 或执行待审脚本。helper 用请求 ID 关联回包；固定可执行文件/参数独立于用户文本。解析工具按实际受管方言选择，不按 Host OS 猜测 Bash/POSIX/Zsh/WSL。

## 有界事实提取

从 AST 提取明确动作、参数位置、字面量目标、有限 cwd/常量与执行上下文；不重建通用 Shell 解释器、跨回合变量表或备份状态机。普通字符串、注释、只定义未调用函数不作为执行；插值、命令/过程替换、带展开 here-doc 的子表达式按 AST 事实处理，条件分支只表示潜在执行。

动态变量、alias、source/eval 和外部脚本可能产生 Unknown。Unknown 是覆盖限制，本身不构成 Deny；只有独立已确认危险事实才触发相应政策。不能把解析成功等同于理解任意 SQL、云 SDK、保存 plan 或远端副作用。

结构化文件工具直接使用明确操作与目标，不经过 Shell Parser。路径按执行平台文件系统语义处理；symlink/Junction、设备身份、Git common-dir、工作区与容器边界需真实证据，不能用文件名代替目标身份。

## 执行身份与最终门禁

1. `tools/pre-execute` 对本次执行异步完成官方 AST、事实提取、策略及必要审批。
2. 使用同一 `ToolExecution` 对象作为 WeakMap key，保存完整判定；不能用文本哈希、裸 callId 或上一调用批准作为授权身份。
3. 同步 `ctx.tools.guard` 只消费已完成判定，实施最终拒绝。它不做异步解析或等待。
4. 必检 Shell 若缺本次可信完整结果，最终 guard 拒绝；即使前置 waterfall 被其他监听器短路，也不能静默执行。
5. 当前允许只绑定当前执行；新的执行对象重新分析和审批。

## 故障与资源生命周期

| 状态 | 执行语义 |
|---|---|
| Provider 不可用、崩溃、超时、异常退出、协议损坏或无效 JSON | fail-closed，明确说明检查基础设施不可用 |
| ParseErrors、语法失败或结构不足 | 拒绝，不能将残缺 AST 当作检查通过 |
| 本次对象的完整关联结果缺失 | 最终 guard 拒绝 |
| 语法有效但效果 Unknown | 不因 Unknown 自动 Deny，披露具体覆盖限制 |

输入、输出字节、JSON 深度、解析等待、并发和进程数量必须有界；具体数值属于工程配置与测量结果，不能宣称未经测量的 p95/p99。取消和插件卸载须清理本次请求、计时器、监听器与子进程；helper 断线后的新请求不得继承旧回包或授权。诊断应脱敏，不回显待审文本内密钥。
