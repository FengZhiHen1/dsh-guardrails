## 已确认规则与实现

| ID / 原则 | 当前实现与限制 |
|---|---|
| 官方 AST / 最终 Guard | 微软 ParseInput 持久 helper、reqId+child 关联；官方 shfmt typed JSON；execution WeakMap；协议、语法、资源与结果关联故障 fail-closed |
| 有界审批 | 默认 120000ms，legacy 0 映射默认；只准 allowed-once；拒绝、取消、超时、迟到、卸载均不授权；全局审批机制未修改 |
| ABS-01 | Linux block+sysfs 物理身份且宿主根身份成立；Windows 固定只读 inventory + 明确选择器 + 物理 bus/UniqueId/online；未识别或无法证明目标为 Unknown |
| ABS-02 | 真实宿主根/关键系统树的明确递归 delete；不把项目/HOME/镜像或一般 move 当作绝对毁坏 |
| ABS-03 | 实际 Git common-dir 或 objects 主体的直接递归 delete；项目根和 linked .git 指针不因此 Deny |
| S-F1 | 精确 Profile 标记与继承的内置文件，直接内容读/写/删/移/复制 Ask；不存在的精确标记写路径也 Ask；元数据 Allow |
| S-F2 | 原生 Worktree remove 默认 Allow，仅实际受保护文件触发 Ask；有界元数据发现，不依赖祖先合并证明 |
| M-S1/M-S2 | 反馈建议运行时凭据注入和非秘密健康检查；不强制迁移 .env |
| R-M1 | 高置信 provider token/Bearer/JWT/完整私钥文本完整遮罩；不以任意高熵字符串阻断 |
| R-M2 | AST 中高置信 inline credential + 认证/外发操作纠正型 Deny；变量、占位符和 echo 文档反例放行 |
| 普通清理 | 不递归内容扫描；普通目录仅检查实际精确标记包含关系；内置文件递归发现只限 S-F2，512 条目/深度8/总预算1500ms |
| 数量辅助提醒 | 本轮无已启用清理纠正型规则需要该附加信息，未设数量阻断或独立扫描；不是已交付通用计数器 |
| 候选矩阵 | Git/链删/云/数据库/容器/系统候选未默认启用 |

正常 Git/Worktree、普通缓存清理、镜像文件与未知目标均有正反例。测试通过率不是人工历史语料误伤率，不报告百分比改善。

## Native/PTC 出口矩阵

使用真实 ToolRuntime、真实 PTC bridge 和合成 in-process provider 验证；不是生产 Python/JS 执行器的全覆盖证明。

| 出口 | 结果 |
|---|---|
| Native post-visible 文本 content | 高置信凭据遮罩，保留成功/失败语义 |
| 无约束 string value + 可安全重新渲染 | value/content 均遮罩，真实 output schema 重新校验通过 |
| 任意 object/enum value | 不通用改写，仍可含明文；仅 content 遮罩 |
| error.message、meta、additionalContexts | 缺通用保真替换接口，仍可能含明文；不宣称净化 |
| Native definition finalizer / projector | 在 post 后可能重新引入明文，未保证最终内容全部遮罩 |
| PTC SDK 子调用 string value | 满足上述 string 契约时遮罩 |
| PTC SDK object value / error | 仍可含明文，已用断言证实该限制 |
| PTC durable settle content | 独立 ptc-dispatch-log hook 遮罩，包括 post 后 finalizer 再产出的合成凭据；4 条 settle 记录测试通过 |
| 顶层 run_code | 经同一 post 文本逻辑；真实外部执行器和错误/meta 等各分支未全部验收 |
| 原生 tool/result 持久化 | 本会话工具返回可见遮罩；未读取本会话压缩日志独立复验磁盘字节，不能扩大为全部持久字段 |
| tool/call、PTC start/settle arguments | 发生在预审前或保留原始参数，不撤销明文 |
| 图片、历史 transcript、direct Node、已发送网络数据 | 未覆盖 |

PTC 日志 hook 若抛异常，运行时会回退原日志；该插件不是零泄漏保证。
